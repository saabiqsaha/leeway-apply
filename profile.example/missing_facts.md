# missing_facts.md: questions only you can answer

The agent adds a line here whenever a form asks for a fact that is not in profile/ (it skips
that posting rather than guess). Answer next to the question, or just tell the agent in a
session; it moves the answer into profile.json or answers.md and deletes the line.

Format the agent uses: `- [ ] (date) Company: "exact question text"`
